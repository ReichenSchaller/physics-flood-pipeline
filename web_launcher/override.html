Override Mode

Use already-processed SFINCS input files. Give the launcher one source path, detect known SFINCS filenames, confirm the override switches, then continue into a Manual Mode-style config where irrelevant tabs are hidden or greyed out.

Config formatnormal JSON
MaintainerReichen Schaller
Versionv1.1 (5/28/26)
← Back to main menu

1. Detect source files and confirm overrides

Enter the source folder containing already-processed SFINCS inputs. Detection checks for known SFINCS filenames and flips matching override switches green. Files not recognized here are not treated as SFINCS-readable override inputs.

Add one or more folders. For example, use one static SFINCS folder and one event folder, then click Detect all.

2. Stripped manual config

No manual tabs are hidden yet. Confirm overrides to update this section.

This keeps the same style as Manual Mode. Source/path rows can grey out when selected override files already provide that product. Master toggles such as use_infiltration, use_wind, and use_pressure stay editable so you can still decide whether those products are active.

4. Data / event catalogs

Add one or more data/event catalog folders here. If this field is blank, Override Mode uses pure native SFINCS assembly from the detected override files. If this field is filled, the launcher switches to hybrid mode, using native override files plus selected catalog/event products.

SettingValueNotes
data_catalogs
One plain path, newline-separated paths, comma-separated paths, or a JSON list is accepted. In Override Mode, detected catalog suggestions are applied only to event/hybrid fields, not native static-file authority.

4. Final submit

This sends the current page config to Flask, saves a staged JSON config, and calls pipeline_runner.py with a safe whitelisted mode. Run backend preflight first, then build scripts, then submit.

If you previously saved progress using the same run_name, the final run folder may already exist. For build/submit, use a new run name unless you intentionally set overwrite_existing_run=true.
