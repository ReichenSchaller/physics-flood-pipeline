Manual Mode

Direct control over a standard SFINCS pipeline JSON config. Fill the tables in any order, save a normal backend config, load an existing config, and use the check tab before moving to backend preflight/build/submit.

10. Subgrid settings

Subgrid controls are important because they affect how fine-scale elevation and roughness are represented inside coarser SFINCS cells. This page supports either generating subgrid data from source inputs or pointing to a pre-made subgrid file.

The pre-made subgrid file option is intentionally separate from full Override Mode. Full Override Mode is for many already-processed SFINCS files; this option is only for using a pre-made subgrid while keeping the rest of the setup manual.
SettingValueNotes
use_subgrid Master toggle for subgrid use.
subgrid_source_kind Choose whether preprocessing should generate subgrid data or use a pre-made SFINCS subgrid file. Backend support may need to be added for this new key.
subgrid_native_file_path
Optional path to an existing SFINCS subgrid file, usually something like sfincs.sbg. This should only matter when subgrid_source_kind is premade_sbgfile.
subgrid_nr_pixels Subgrid pixels per model cell. Higher values can improve detail but increase preprocessing cost and storage.
subgrid_write_dep_tif Write depth/elevation diagnostic GeoTIFF during subgrid creation.
subgrid_write_man_tif Write Manning roughness diagnostic GeoTIFF during subgrid creation.
subgrid_use_rivers Use river network information in subgrid generation when supported by the preprocessing path.
subgrid_river_path
Optional river geometry path for subgrid processing.
subgrid_river_source River source name in a HydroMT catalog.
use_spatially_variable_roughness Related roughness/subgrid behavior. Keep aligned with the roughness settings tab.

Save/load behavior

Save downloads the same normal JSON config format that the backend runner should accept. Load accepts existing JSON configs and fills any matching fields.

Static HTML can download and load files, but it cannot browse or create folders in /proj. The disabled Browse/New Folder controls are placeholders for the Flask version.
