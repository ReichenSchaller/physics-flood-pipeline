Override Mode

Use already-processed SFINCS input files. Give the launcher one source path, detect known SFINCS filenames, confirm the override switches, then continue into a Manual Mode-style config where irrelevant tabs are hidden or greyed out.

1. Detect source files and confirm overrides

Enter the source folder containing already-processed SFINCS inputs. Detection checks for known SFINCS filenames and flips matching override switches green. Files not recognized here are not treated as SFINCS-readable override inputs.

Add one or more folders. For example, use one static SFINCS folder and one event folder, then click Detect all.

2. Stripped manual config

This keeps the same style as Manual Mode. Whole tabs disappear when the selected override files fully cover that work. Rows that are only partly covered stay visible but greyed out.
